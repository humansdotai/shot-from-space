# THIRD-PARTY NOTICES

## interior[.]dev — https://github.com/ddoemonn/interior

Files under `components/interior/` are vendored from interior[.]dev, a
copy-in micro-interaction library. Its own README states there is no package:
each component is a single file intended to be copied into the consuming
project, exposing a headless hook plus a styled example meant to be reskinned.
We use it exactly that way.

Vendored: `value-flash`, `streaming-text`, `blur-up-image`, `copy-button`.
Runtime dependency: `motion` (motion.dev).
